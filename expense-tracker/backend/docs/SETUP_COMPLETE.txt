BEFORE RUNNING ANYTHING:

1. PostgreSQL must be running
   Windows:   Get-Service PostgreSQL* | Start-Service

   Linux:     sudo systemctl start postgresql

   psql -U postgres -c "CREATE DATABASE expense_tracker;"

3. Update .env with your credentials
   nano .env  (or notepad .env on Windows)
   Change DB_PASSWORD to your PostgreSQL password

4. Never commit .env file
   Already excluded by .gitignore ✓

💡 TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────────────

Connection Refused?
  → PostgreSQL not running: brew services start postgresql@15

Password Failed?
  → Wrong password in .env: psql -U postgres -c "ALTER USER postgres WITH PASSWORD 'newpass';"

Database Not Found?
  → Create it: psql -U postgres -c "CREATE DATABASE expense_tracker;"

Port 5432 Busy?
  → Check: netstat -an | grep 5432
  → Another app using it, change DB_PORT in .env

Cannot Import asyncpg?
  → Reinstall: pip install --upgrade asyncpg
