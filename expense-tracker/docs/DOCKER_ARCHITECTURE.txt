✨ KEY FEATURES
────────────────────────────────────────────────────────────────────────────────

DATABASE:
  ✓ Lightweight: postgres:15-alpine (minimal footprint)
  ✓ Persistent: Named volume survives container restarts
  ✓ Health Check: Validates readiness before backend starts
  ✓ Credentials: admin / supersecret (development only!)

BACKEND:
  ✓ Multi-stage build: Smaller final image (~300MB vs 900MB+)
  ✓ Auto-restart: Restarts if crash (unless-stopped)
  ✓ Health check: API responds to /health endpoint
  ✓ DNS resolution: Uses "db" hostname (Docker internal)
  ✓ Flexible env vars: DATABASE_URL or individual DB_* vars

NETWORKING:
  ✓ Bridge network: Both services on same network
  ✓ Service discovery: Docker DNS resolves names to IPs
  ✓ Isolation: Services can't reach host network by default
  ✓ Port mapping: Host ports (5432, 8000) → container ports
